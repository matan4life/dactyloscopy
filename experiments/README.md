# experiments/

Experiment declarations: what is compared with what, on which manifests, under which protocol and metric ids, with which seed. A declaration says what a run will do before it is run.
A declaration holds no result and no number that was measured. Results belong in `runs/`, with their observations beside them as `quality/REF-016` decides; code belongs with the implementation.
Not here: data, derived artifacts, or a declaration that addresses a dataset by path instead of by manifest id.
