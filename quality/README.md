# quality/

The INV and REF chain. `INV-nnn-*.md` is an investigation: a question, a method, measured facts, a command that reproduces them, a date, and what was left unchecked. It holds no decisions, no judgements and no recommendations.
`REF-nnn-*.md` is a refinement: a decision taken on the facts of named investigations, with the alternatives considered and why each was rejected. It holds no new facts; every factual claim points at an INV.
A fact and a decision never share a file. The consequence of a refinement is a manifest in `manifests/`, never a file here.
Not here: manifests, run records, code, or a decision that names no INV.
