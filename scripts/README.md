# scripts/

Scripts run from the command line: the command form of each measurement instrument, of the matching run and of its reproduction, the placer that puts a finished record under `runs/`, and two checks, `verify_manifests.py` and `check_tools.sh`, that hold every manifest and the tools in the image to what the manifests declare.
A script here may start a run - `run_matching.py` is what `make run-matching` invokes - but it holds no mechanism. Nothing in this directory computes a number that a result depends on; the code that does belongs under `implementation/`, and a script only reaches it.
A script may be the command form of a module under `implementation/`, in which case it imports and calls and does nothing else, so that a run and a person reach the same code by the same path. The six `measure_*.py`, `run_matching.py` and `reproduce_matching.py` are that shape; `verify_manifests.py` imports and calls and then formats the report in the script, which `docs/manifests.md` records as a finding not acted on; `check_tools.sh` carries its checks in the script, driven by `manifests/MAN-tools.v2.json` rather than by a module; `record_run.py` runs on the host, through `make record-run`, after `make run-matching`: it places a finished record under `runs/` at the id `quality/REF-017` gives it, prints the trailers of its `run:` commit, and refuses a record that is provisional, was made at a revision other than `HEAD`, or does not digest to its observation.
Each command form is a Python file run as `python3 scripts/<name>.py`, with its arguments parsed by `argparse` and its imports taken from the tree the file sits in, so `python3 <copy>/scripts/verify_manifests.py` verifies a copy of the tree with the copy's own code. Until 2026-09-22 each was a shell script that embedded the same Python in a heredoc; the shell layer carried no logic and was dropped so that the command form is one file in one language, and a reader of `--help` sees the arguments.
Not here: experiment logic, metric code, or anything a result depends on.
