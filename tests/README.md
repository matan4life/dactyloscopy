# tests/

Tests, run by `pytest` inside the image that `make test` builds and never against a toolchain on the author's machine.
A test here checks a property that could be wrong: byte-exactness where the bytes are stable, and a declared tolerance where they are not. A test that fails for a reason nobody cares about is a defect in the test, not a finding, and `quality/REF-013` decision 2 says why that rule exists.
Every input a test uses is generated by the test, from constants the test states, so that what a test asserts can be read without opening a data directory.
Not here: a corpus image, a minutia, a template, a fixture that reaches outside the tree, or a test whose failure would be uninteresting.
