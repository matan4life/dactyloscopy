# runs/

Run records and the observations that support claims: a `results.json` per run, with the pair list and score vector it was computed from. What a record carries is decided in `quality/REF-016-run-record-composition.md`: the dataset and its manifest by digest, the comparison lists by digest, each tool by measured digest, the code revision with whether the tree was dirty, the seed, the counts, and each metric by id and version with its registered definition from `manifests/MAN-metrics.v1.json`; a record missing any of them is not a result. Metrics are stored as fractions. A record lives at `runs/<id>/`; an observation over 5 MB lives under `$LABDATA/derived/observations/<id>/` and the record carries its sha256 and byte count. Nothing is here yet: the two runs `quality/INV-017-run-record-composition.md` made were written under `$LABDATA/derived` before the composition was decided, and no `run:` commit exists.
A commit that records a run uses the `run:` prefix and carries the headline metric in its subject.
Not here: images, minutiae, or any observation from which either could be reconstructed.
